# 🎬 유튜브 댓글 수집기 (YouTube Comment Collector)

유튜브 영상 URL만 입력하면 **복잡한 YouTube Data API 키 발급 없이도** 댓글과 대댓글을 간편하게 수집하고, 엑셀/CSV/텍스트 파일로 다운로드할 수 있는 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **간편한 주소 입력 & 영상 자동 미리보기**
   - 일반 영상(`watch?v=...`), 공유 단축 링크(`youtu.be/...`), 쇼츠(`shorts/...`) 모두 지원
   - URL 입력 시 영상 제목, 채널명, 썸네일 자동 표시

2. **유연한 수집 옵션 설정**
   - **정렬 옵션**: 인기순(Top) / 최신순(Newest) 선택 가능
   - **수집 개수 설정**: 슬라이더(20~2,000개) 또는 '댓글 전체 수집' 모드 지원
   - **대댓글(답글) 포함 여부** 선택 가능

3. **실시간 진행률 및 통계 요약**
   - 실시간 수집 개수 및 프로그레스 바 표시
   - 총 댓글 수, 고유 작성자 수, 대댓글 수, 하트 받은 댓글 수, 최다 좋아요 수 한눈에 확인

4. **다양한 파일 형식 다운로드**
   - 📥 **Excel (.xlsx)**: 서식이 적용된 엑셀 파일
   - 📄 **CSV (.csv)**: UTF-8-BOM 인코딩으로 엑셀에서 한글 깨짐 없는 CSV
   - 📝 **AI 분석용 TXT (.txt)**: ChatGPT나 Gemini 등에 업로드하여 여론 분석/요약하기 좋은 텍스트 형식

5. **인터랙티브 데이터 뷰 & 분석**
   - 📋 **전체 댓글 목록**: 정렬 및 스크롤 가능한 테이블 (작성일시 및 수집일시 표기)
   - 🔥 **베스트 댓글 TOP 5**: 좋아요를 가장 많이 받은 댓글 카드 하이라이트
   - 📊 **텍스트 분석 & 차트 시각화**:
     - **최다 언급 키워드 TOP N 막대 그래프**: 빈출 단어 자동 추출 및 추가 불용어 필터링
     - **일자별 댓글 등록 추이 선 그래프**: 영상 공개 후 언제 댓글이 집중되었는지 추이 분석
     - **댓글 글자 수(길이) 구간별 분포 그래프**: 단문/중문/장문 비율 분석
     - **좋아요 순위 TOP 10 댓글 비교 그래프**: 시청자 공감을 가장 많이 얻은 댓글 시각화
   - 🔍 **검색 및 필터링**: 특정 키워드나 작성자 이름 검색, 댓글/답글 구분 필터

## 🚀 실행 방법

### 방법 1. 원클릭 실행 (Windows)
폴더 안의 **`run.bat`** 파일을 더블 클릭하면 브라우저에서 웹앱이 자동으로 실행됩니다.

### 방법 2. 터미널(콘솔)에서 실행
```bash
# 1. 필수 패키지 설치 (최초 1회)
pip install -r requirements.txt

# 2. 웹앱 실행
python -m streamlit run app.py
```
실행 후 터미널에 표시되는 로컬 주소(기본: `http://localhost:8501`)로 웹 브라우저가 자동 열립니다.

## 📁 파일 구성

- `app.py`: Streamlit 웹 애플리케이션 UI 및 제어 로직
- `utils.py`: 유튜브 댓글 다운로더, 비디오 정보 파싱, 엑셀/CSV 변환 모듈
- `requirements.txt`: 필요한 파이썬 라이브러리 목록
- `run.bat`: 윈도우 원클릭 실행 스크립트
- `README.md`: 사용 설명서
